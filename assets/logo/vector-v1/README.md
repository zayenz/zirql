# Zirql logo variants

The SVGs trace the selected logo shapes into paths. They have transparent
backgrounds and outlined lettering, with no embedded bitmap or font dependency.
Each layout has matching light and dark SVGs and transparent PNG exports.

Use the light variant on white or pale backgrounds. Use the dark variant on
navy or charcoal backgrounds. The extraction square and i dot retain the
same royal blue in both themes.

| Color | Light | Dark |
| --- | --- | --- |
| Main shape and lettering | `#203044` | `#D1DEEC` |
| Interior cells | `#9EB2C8` | `#91A9C2` |
| Blue accent | `#236BF2` | `#236BF2` |

`horizontal-compact` is used in the documentation header and project card.
The other layouts are `horizontal`, `stacked`, `glyph` and `wordmark`.
The original selected PNGs remain in `../selected-v1/`.
